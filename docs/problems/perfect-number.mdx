## Problem

A &lt;a href="https://en.wikipedia.org/wiki/Perfect_number" target="_blank">&lt;strong>perfect number&lt;/strong>&lt;/a> is a &lt;strong>positive integer&lt;/strong> that is equal to the sum of its &lt;strong>positive divisors&lt;/strong>, excluding the number itself. A &lt;strong>divisor&lt;/strong> of an integer &lt;code>x&lt;/code> is an integer that can divide &lt;code>x&lt;/code> evenly.

Given an integer &lt;code>n&lt;/code>, return &lt;code>true&lt;/code>&lt;em> if &lt;/em>&lt;code>n&lt;/code>&lt;em> is a perfect number, otherwise return &lt;/em>&lt;code>false&lt;/code>.

### Examples

```
Input: num = 28
Output: true
Explanation: 28 = 1 + 2 + 4 + 7 + 14
1, 2, 4, 7, and 14 are all divisors of 28.
```

```
Input: num = 7
Output: false
```

### Constraints

- `1 <= num <= 10^8`

```python
class Solution:
    # Time: O(sqrt(n))
    # Space: O(1)
    def check_perfect_number(self, num: int) -> bool:
        if num <= 1:
            return False
        total = 1
        i = 2
        while i * i <= num:
            if num % i == 0:
                total += i
                paired = num // i
                if paired != i:
                    total += paired
            i += 1
        return total == num
```
