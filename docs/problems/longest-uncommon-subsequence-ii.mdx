## Problem

Given an array of strings &lt;code>strs&lt;/code>, return &lt;em>the length of the &lt;strong>longest uncommon subsequence&lt;/strong> between them&lt;/em>. If the longest uncommon subsequence does not exist, return &lt;code>-1&lt;/code>.

An &lt;strong>uncommon subsequence&lt;/strong> between an array of strings is a string that is a &lt;strong>subsequence of one string but not the others&lt;/strong>.

A &lt;strong>subsequence&lt;/strong> of a string &lt;code>s&lt;/code> is a string that can be obtained after deleting any number of characters from &lt;code>s&lt;/code>.

&lt;ul>
&lt;li>For example, &lt;code>&quot;abc&quot;&lt;/code> is a subsequence of &lt;code>&quot;aebdc&quot;&lt;/code> because you can delete the underlined characters in &lt;code>&quot;a&lt;u>e&lt;/u>b&lt;u>d&lt;/u>c&quot;&lt;/code> to get &lt;code>&quot;abc&quot;&lt;/code>. Other subsequences of &lt;code>&quot;aebdc&quot;&lt;/code> include &lt;code>&quot;aebdc&quot;&lt;/code>, &lt;code>&quot;aeb&quot;&lt;/code>, and &lt;code>&quot;&quot;&lt;/code> (empty string).&lt;/li>
&lt;/ul>

### Examples

```
Input: strs = ["aba","cdc","eae"]
Output: 3
```

```
Input: strs = ["aaa","aaa","aa"]
Output: -1
```

### Constraints

- 2 &lt;= strs.length &lt;= 50
- 1 &lt;= strs[i].length &lt;= 10
- strs[i] consists of lowercase English letters.

## Solution

```python
class Solution:
    # Time: O(n^2 * (len_i + len_j))
    # Space: O(1)
    def find_lus_length(self, strs: list[str]) -> int:
        # A longest uncommon subsequence, when one exists, can always be taken
        # as one of the input strings in full: any candidate longer than every
        # string it could embed in is already uncommon, so extending it never
        # helps. So scan each string and keep the longest one that is not a
        # subsequence of any other string (duplicates disqualify each other).
        def is_subsequence(short: str, long: str) -> bool:
            if len(short) > len(long):
                return False
            i = 0
            for ch in long:
                if i < len(short) and short[i] == ch:
                    i += 1
            return i == len(short)

        best = -1
        for i, candidate in enumerate(strs):
            if any(
                is_subsequence(candidate, other)
                for j, other in enumerate(strs)
                if i != j and len(other) >= len(candidate)
            ):
                continue
            best = max(best, len(candidate))
        return best
```
