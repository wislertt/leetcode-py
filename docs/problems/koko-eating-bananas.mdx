## Problem

Koko loves to eat bananas. There are `n` piles of bananas, the `i<sup>th</sup>` pile has `piles[i]` bananas. The guards have gone and will come back in `h` hours.

Koko can decide her bananas-per-hour eating speed of `k`. Each hour, she chooses some pile of bananas and eats `k` bananas from that pile. If the pile has less than `k` bananas, she eats all of them instead and will not eat any more bananas during this hour.

Koko likes to eat slowly but still wants to finish eating all the bananas before the guards return.

Return _the minimum integer_ `k` _such that she can eat all the bananas within_ `h` _hours_.

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/koko_eating_bananas/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/koko_eating_bananas/test_solution.py):

```python
import math


class Solution:
    # Time: O(n log m) where n = piles, m = max(piles)
    # Space: O(1)
    def min_eating_speed(self, piles: list[int], h: int) -> int:
        left, right = 1, max(piles)
        result = right
        while left <= right:
            speed = (left + right) // 2
            hours_needed = sum(math.ceil(pile / speed) for pile in piles)
            if hours_needed <= h:
                result = speed  # speed works, try slower
                right = speed - 1
            else:
                left = speed + 1  # too slow, eat faster
        return result
```
