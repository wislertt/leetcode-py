## Problem

Given an input string `s`, reverse the order of the words. A word is defined as a sequence of non-space characters. The words in `s` will be separated by at least one space. Return a string of the words in reverse order concatenated by a single space.

### Examples

```
Input: s = "the sky is blue"
Output: "blue is sky the"
```

```
Input: s = "  hello world  "
Output: "world hello"
Explanation: Your reversed string should not contain leading or trailing spaces.
```

```
Input: s = "a good   example"
Output: "example good a"
Explanation: You need to reduce multiple spaces between two words to a single space in the reversed string.
```

### Constraints

- 1 &lt;= s.length &lt;= 10^4
- s contains English letters (upper-case and lower-case), digits, and spaces ' '.
- There is at least one word in s.

**Follow up:** If the string data type is mutable in your language, can you solve it in-place with O(1) extra space?

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/reverse_words_in_a_string/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/reverse_words_in_a_string/test_solution.py):

```python
class Solution:
    # Time: O(n) where n is the length of the string
    # Space: O(n) for the split list
    def reverse_words(self, s: str) -> str:
        # Split by whitespace (handles multiple spaces)
        words = s.split()
        # Reverse the list and join with single space
        return " ".join(reversed(words))
```
