## Problem

Given a list of 24-hour clock time points in **"HH:MM"** format, return *the minimum **minutes** difference between any two time-points in the list*.

### Examples

```
Input: timePoints = ["23:59","00:00"]
Output: 1
```

```
Input: timePoints = ["00:00","23:59","00:00"]
Output: 0
```

### Constraints

- `2 <= timePoints.length <= 2 * 10^4`
- `timePoints[i]` is in the format **"HH:MM"**.

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_time_difference/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_time_difference/test_solution.py):

```python
class Solution:
    # Time: O(n log n)
    # Space: O(n)
    def find_min_difference(self, time_points: list[str]) -> int:
        minutes = sorted(int(t[:2]) * 60 + int(t[3:]) for t in time_points)
        best = 24 * 60 - (minutes[-1] - minutes[0])
        for i in range(len(minutes) - 1):
            best = min(best, minutes[i + 1] - minutes[i])
        return best
```
