## Problem

Given a list of words, list of  single letters (might be repeating) and score of every character.

Return the maximum score of any valid set of words formed by using the given letters (words[i] cannot be used two or more times).

It is not necessary to use all characters in &lt;code>letters&lt;/code> and each letter can only be used once. Score of letters &lt;code>'a'&lt;/code>, &lt;code>'b'&lt;/code>, &lt;code>'c'&lt;/code>, ... ,&lt;code>'z'&lt;/code> is given by &lt;code>score[0]&lt;/code>, &lt;code>score[1]&lt;/code>, ... , &lt;code>score[25]&lt;/code> respectively.

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/maximum_score_words_formed_by_letters/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/maximum_score_words_formed_by_letters/test_solution.py):

```python
from collections import Counter


class Solution:
    def max_score_words(self, words: list[str], letters: list[str], score: list[int]) -> int:
        word_counts = [Counter(word) for word in words]
        word_scores = [
            sum(score[ord(c) - 97] * cnt for c, cnt in Counter(word).items()) for word in words
        ]
        n = len(words)

        def backtrack(i: int, available: Counter) -> int:
            if i == n:
                return 0
            best = backtrack(i + 1, available)
            counts = word_counts[i]
            if all(available[c] >= cnt for c, cnt in counts.items()):
                for c, cnt in counts.items():
                    available[c] -= cnt
                best = max(best, word_scores[i] + backtrack(i + 1, available))
                for c, cnt in counts.items():
                    available[c] += cnt
            return best

        return backtrack(0, Counter(letters))
```
