## Problem

Given a sorted integer array &lt;code>nums&lt;/code> and an integer &lt;code>n&lt;/code>, add/patch elements to the array such that any number in the range &lt;code>[1, n]&lt;/code> inclusive can be formed by the sum of some elements in the array.

Return &lt;em>the minimum number of patches required&lt;/em>.

### Examples

```
Input: nums = [1,3], n = 6
Output: 1
Explanation:
Combinations of nums are [1], [3], [1,3], which form possible sums of: 1, 3, 4.
Now if we add/patch 2 to nums, the combinations are: [1], [2], [3], [1,3], [2,3], [1,2,3].
Possible sums are 1, 2, 3, 4, 5, 6, which now covers the range [1, 6].
So we only need 1 patch.
```

```
Input: nums = [1,5,10], n = 20
Output: 2
Explanation: The two patches can be [2, 4].
```

```
Input: nums = [1,2,2], n = 5
Output: 0
```

### Constraints

- 1 &lt;= nums.length &lt;= 1000
- 1 &lt;= nums[i] &lt;= 10^4
- nums is sorted in ascending order.
- 1 &lt;= n &lt;= 2^31 - 1

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/patching_array/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/patching_array/test_solution.py):

```python
class Solution:
    # Time: O(len(nums) + log n)
    # Space: O(1)
    def min_patches(self, nums: list[int], n: int) -> int:
        patches = 0
        miss = 1  # smallest sum in [1, miss) that cannot be formed yet
        i = 0
        while miss <= n:
            if i < len(nums) and nums[i] <= miss:
                miss += nums[i]
                i += 1
            else:
                patches += 1
                miss += miss
        return patches
```
