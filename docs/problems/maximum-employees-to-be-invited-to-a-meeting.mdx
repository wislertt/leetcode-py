## Problem

A company is organizing a meeting and has a list of &lt;code>n&lt;/code> employees, waiting to be invited. They have arranged for a large &lt;strong>circular&lt;/strong> table, capable of seating &lt;strong>any number&lt;/strong> of employees.&lt;/p>

&lt;p>The employees are numbered from &lt;code>0&lt;/code> to &lt;code>n - 1&lt;/code>. Each employee has a &lt;strong>favorite&lt;/strong> person and they will attend the meeting &lt;strong>only if&lt;/strong> they can sit next to their favorite person at the table. The favorite person of an employee is &lt;strong>not&lt;/strong> themself.&lt;/p>

&lt;p>Given a &lt;strong>0-indexed&lt;/strong> integer array &lt;code>favorite&lt;/code>, where &lt;code>favorite[i]&lt;/code> denotes the favorite person of the &lt;code>i&lt;sup>th&lt;/sup>&lt;/code> employee, return &lt;em>the &lt;strong>maximum number of employees&lt;/strong> that can be invited to the meeting&lt;/em>.

### Constraints

- n == favorite.length
- 2 &lt;= n &lt;= 10^5
- 0 &lt;= favorite[i] &lt;= n - 1
- favorite[i] != i

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/maximum_employees_to_be_invited_to_a_meeting/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/maximum_employees_to_be_invited_to_a_meeting/test_solution.py):

```python
from collections import deque


class Solution:
    # Time: O(n)
    # Space: O(n)
    def maximum_invitations(self, favorite: list[int]) -> int:
        n = len(favorite)
        depth = [1] * n
        indegree = [0] * n
        for fav in favorite:
            indegree[fav] += 1

        # Peel off chain nodes so only cycle nodes keep indegree > 0, recording
        # for each cycle node the longest chain of excluded employees hanging
        # off it (depth counts the cycle node itself).
        queue = deque(i for i in range(n) if indegree[i] == 0)
        in_cycle = [True] * n
        while queue:
            node = queue.popleft()
            in_cycle[node] = False
            nxt = favorite[node]
            depth[nxt] = max(depth[nxt], depth[node] + 1)
            indegree[nxt] -= 1
            if indegree[nxt] == 0:
                queue.append(nxt)

        visited = [False] * n
        best_cycle = 0
        pair_total = 0
        for start in range(n):
            if not in_cycle[start] or visited[start]:
                continue
            length = 0
            node = start
            while not visited[node]:
                visited[node] = True
                node = favorite[node]
                length += 1
            if length == 2:
                # Mutual pairs can all sit together if their chains face them.
                pair_total += depth[start] + depth[favorite[start]]
            else:
                best_cycle = max(best_cycle, length)
        return max(best_cycle, pair_total)
```
