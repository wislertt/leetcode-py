## Problem

A &lt;strong>boolean expression&lt;/strong> is an expression that evaluates to either &lt;code>true&lt;/code> or &lt;code>false&lt;/code>. It can be in one of the following shapes:

- &lt;code>&#39;t&#39;&lt;/code> that evaluates to &lt;code>true&lt;/code>.
- &lt;code>&#39;f&#39;&lt;/code> that evaluates to &lt;code>false&lt;/code>.
- &lt;code>&#39;!(subExpr)&#39;&lt;/code> that evaluates to &lt;strong>the logical NOT&lt;/strong> of the inner expression &lt;code>subExpr&lt;/code>.
- &lt;code>&#39;&amp;(subExpr&lt;sub>1&lt;/sub>, subExpr&lt;sub>2&lt;/sub>, ..., subExpr&lt;sub>n&lt;/sub>)&#39;&lt;/code> that evaluates to &lt;strong>the logical AND&lt;/strong> of the inner expressions &lt;code>subExpr&lt;sub>1&lt;/sub>, subExpr&lt;sub>2&lt;/sub>, ..., subExpr&lt;sub>n&lt;/sub>&lt;/code> where &lt;code>n &gt;= 1&lt;/code>.
- &lt;code>&#39;|(subExpr&lt;sub>1&lt;/sub>, subExpr&lt;sub>2&lt;/sub>, ..., subExpr&lt;sub>n&lt;/sub>)&#39;&lt;/code> that evaluates to &lt;strong>the logical OR&lt;/strong> of the inner expressions &lt;code>subExpr&lt;sub>1&lt;/sub>, subExpr&lt;sub>2&lt;/sub>, ..., subExpr&lt;sub>n&lt;/sub>&lt;/code> where &lt;code>n &gt;= 1&lt;/code>.

Given a string &lt;code>expression&lt;/code> that represents a &lt;strong>boolean expression&lt;/strong>, return &lt;em>the evaluation of that expression&lt;/em>.

It is &lt;strong>guaranteed&lt;/strong> that the given expression is valid and follows the given rules.

### Examples

```
Input: expression = "&(|(f))"
Output: false
Explanation: First, evaluate |(f) --> f. The expression is now "&(f)". Then, evaluate &(f) --> f. The expression is now "f". Finally, return false.
```

```
Input: expression = "|(f,f,f,t)"
Output: true
Explanation: The evaluation of (false OR false OR false OR true) is true.
```

```
Input: expression = "!(&(f,t))"
Output: true
Explanation: First, evaluate &(f,t) --> (false AND true) --> false --> f. The expression is now "!(f)". Then, evaluate !(f) --> NOT false --> true. We return true.
```

### Constraints

- &lt;code>1 &lt;= expression.length &lt;= 2 * 10&lt;sup>4&lt;/sup>&lt;/code>
- &lt;code>expression[i]&lt;/code> is one following characters: &lt;code>&#39;(&#39;&lt;/code>, &lt;code>&#39;)&#39;&lt;/code>, &lt;code>&#39;&amp;&#39;&lt;/code>, &lt;code>&#39;|&#39;&lt;/code>, &lt;code>&#39;!&#39;&lt;/code>, &lt;code>&#39;t&#39;&lt;/code>, &lt;code>&#39;f&#39;&lt;/code>, and &lt;code>&#39;,&#39;&lt;/code>.

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/parsing_a_boolean_expression/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/parsing_a_boolean_expression/test_solution.py):

```python
class Solution:
    # Time: O(n)
    # Space: O(n)
    def parse_bool_expr(self, expression: str) -> bool:
        stack: list[str] = []
        for ch in expression:
            if ch == ",":
                continue
            if ch != ")":
                stack.append(ch)
                continue
            seen: list[bool] = []
            while stack[-1] in ("t", "f"):
                seen.append(stack.pop() == "t")
            stack.pop()
            op = stack.pop()
            if op == "!":
                stack.append("t" if not seen[0] else "f")
            elif op == "&":
                stack.append("t" if all(seen) else "f")
            else:
                stack.append("t" if any(seen) else "f")
        return stack[-1] == "t"
```
