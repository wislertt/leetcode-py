## Problem

&lt;p>For a binary tree &lt;strong>T&lt;/strong>, we can define a &lt;strong>flip operation&lt;/strong> as follows: choose any node, and swap the left and right child subtrees.&lt;/p>

&lt;p>A binary tree &lt;strong>X&lt;/strong>&nbsp;is &lt;strong>flip equivalent&lt;/strong> to a binary tree &lt;strong>Y&lt;/strong> if and only if we can make &lt;strong>X&lt;/strong> equal to &lt;strong>Y&lt;/strong> after some number of flip operations.&lt;/p>

&lt;p>Given the roots of two binary trees &lt;code>root1&lt;/code> and &lt;code>root2&lt;/code>, return &lt;code>true&lt;/code> if the two trees are flip equivalent or &lt;code>false&lt;/code> otherwise.&lt;/p>

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/flip_equivalent_binary_trees/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/flip_equivalent_binary_trees/test_solution.py):

```python
from leetcode_py import TreeNode


class Solution:
    # Time: O(n)
    # Space: O(h) where h is the tree height
    def flip_equiv(self, root1: TreeNode[int] | None, root2: TreeNode[int] | None) -> bool:
        if root1 is None or root2 is None:
            return root1 is root2
        if root1.val != root2.val:
            return False
        no_flip = self.flip_equiv(root1.left, root2.left) and self.flip_equiv(
            root1.right, root2.right
        )
        flip = self.flip_equiv(root1.left, root2.right) and self.flip_equiv(root1.right, root2.left)
        return no_flip or flip
```
