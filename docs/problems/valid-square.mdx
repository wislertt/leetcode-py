## Problem

Given the coordinates of four points in 2D space &lt;code>p1&lt;/code>, &lt;code>p2&lt;/code>, &lt;code>p3&lt;/code> and &lt;code>p4&lt;/code>, return &lt;code>true&lt;/code> &lt;em>if the four points construct a square&lt;/em>.

&lt;p>The coordinate of a point &lt;code>p&lt;sub>i&lt;/sub>&lt;/code> is represented as &lt;code>[x&lt;sub>i&lt;/sub>, y&lt;sub>i&lt;/sub>]&lt;/code>. The input is &lt;strong>not&lt;/strong> given in any order.&lt;/p>

&lt;p>A &lt;strong>valid square&lt;/strong> has four equal sides with positive length and four equal angles (90-degree angles).&lt;/p>

### Examples

```
Input: p1 = [0,0], p2 = [1,1], p3 = [1,0], p4 = [0,1]
Output: true
```

```
Input: p1 = [0,0], p2 = [1,1], p3 = [1,0], p4 = [0,12]
Output: false
```

```
Input: p1 = [1,0], p2 = [-1,0], p3 = [0,1], p4 = [0,-1]
Output: true
```

### Constraints

- p1.length == p2.length == p3.length == p4.length == 2
- -10^4 &lt;= xi, yi &lt;= 10^4

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/valid_square/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/valid_square/test_solution.py):

```python
class Solution:
    # Time: O(1) - always 6 pairwise distances over 4 fixed points
    # Space: O(1)
    def valid_square(self, p1: list[int], p2: list[int], p3: list[int], p4: list[int]) -> bool:
        pts = (p1, p2, p3, p4)
        dists = sorted(
            (a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2 for i, a in enumerate(pts) for b in pts[i + 1 :]
        )
        return 0 < dists[0] == dists[3] and dists[4] == dists[5] == 2 * dists[0]
```
