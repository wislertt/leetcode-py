## Problem

Let &lt;code>f(x)&lt;/code> be the number of zeroes at the end of &lt;code>x!&lt;/code>. Recall that &lt;code>x! = 1 * 2 * 3 * ... * x&lt;/code> and by convention, &lt;code>0! = 1&lt;/code>.

&lt;ul>
	&lt;li>For example, &lt;code>f(3) = 0&lt;/code> because &lt;code>3! = 6&lt;/code> has no zeroes at the end, while &lt;code>f(11) = 2&lt;/code> because &lt;code>11! = 39916800&lt;/code> has two zeroes at the end.&lt;/li>
&lt;/ul>

&lt;p>Given an integer &lt;code>k&lt;/code>, return &lt;em>the number of non-negative integers&lt;/em> &lt;code>x&lt;/code> &lt;em>have the property that&lt;/em> &lt;code>f(x) = k&lt;/code>.&lt;/p>

### Examples

```
Input: k = 0
Output: 5
Explanation: 0!, 1!, 2!, 3!, and 4! end with k = 0 zeroes.
```

```
Input: k = 5
Output: 0
Explanation: There is no x such that x! ends in k = 5 zeroes.
```

```
Input: k = 3
Output: 5
```

### Constraints

- 0 &lt;= k &lt;= 10^9

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/preimage_size_of_factorial_zeroes_function/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/preimage_size_of_factorial_zeroes_function/test_solution.py):

```python
class Solution:
    # Time: O(log^2 k)
    # Space: O(1)
    def preimage_size_fzf(self, k: int) -> int:
        def zeroes(x: int) -> int:
            count = 0
            power = 5
            while power <= x:
                count += x // power
                power *= 5
            return count

        def first_with_at_least(target: int) -> int:
            low, high = 0, 5 * (target + 1)
            while low < high:
                mid = (low + high) // 2
                if zeroes(mid) >= target:
                    high = mid
                else:
                    low = mid + 1
            return low

        left = first_with_at_least(k)
        if zeroes(left) != k:
            return 0
        return first_with_at_least(k + 1) - left
```
