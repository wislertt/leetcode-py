## Problem

There is a &lt;strong>directed graph&lt;/strong> of &lt;code>n&lt;/code> colored nodes and &lt;code>m&lt;/code> edges. The nodes are numbered from &lt;code>0&lt;/code> to &lt;code>n - 1&lt;/code>.

You are given a string &lt;code>colors&lt;/code> where &lt;code>colors[i]&lt;/code> is a lowercase English letter representing the &lt;strong>color&lt;/strong> of the &lt;code>i&lt;sup>th&lt;/sup>&lt;/code> node in this graph (&lt;strong>0-indexed&lt;/strong>). You are also given a 2D array &lt;code>edges&lt;/code> where &lt;code>edges[j] = [a&lt;sub>j&lt;/sub>, b&lt;sub>j&lt;/sub>]&lt;/code> indicates that there is a &lt;strong>directed edge&lt;/strong> from node &lt;code>a&lt;sub>j&lt;/sub>&lt;/code> to node &lt;code>b&lt;sub>j&lt;/sub>&lt;/code>.

A valid &lt;strong>path&lt;/strong> in the graph is a sequence of nodes &lt;code>x&lt;sub>1&lt;/sub> -&gt; x&lt;sub>2&lt;/sub> -&gt; x&lt;sub>3&lt;/sub> -&gt; ... -&gt; x&lt;sub>k&lt;/sub>&lt;/code> such that there is a directed edge from &lt;code>x&lt;sub>i&lt;/sub>&lt;/code> to &lt;code>x&lt;sub>i+1&lt;/sub>&lt;/code> for every &lt;code>1 &lt;= i &lt; k&lt;/code>. The &lt;strong>color value&lt;/strong> of the path is the number of nodes that are colored the &lt;strong>most frequently&lt;/strong> occurring color along that path.

Return &lt;em>the &lt;strong>largest color value&lt;/strong> of any valid path in the given graph, or &lt;/em>&lt;code>-1&lt;/code>&lt;em> if the graph contains a cycle&lt;/em>.

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/largest_color_value_in_a_directed_graph/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/largest_color_value_in_a_directed_graph/test_solution.py):

```python
class Solution:
    # Time: O(n + m) with a constant factor of 26 colors
    # Space: O(n)
    def largest_path_value(self, colors: str, edges: list[list[int]]) -> int:
        n = len(colors)
        adj: list[list[int]] = [[] for _ in range(n)]
        indegree = [0] * n
        for src, dst in edges:
            adj[src].append(dst)
            indegree[dst] += 1

        counts = [[0] * 26 for _ in range(n)]
        for node in range(n):
            counts[node][ord(colors[node]) - 97] = 1
        queue = [node for node in range(n) if indegree[node] == 0]
        processed = 0
        best = 0

        while queue:
            node = queue.pop()
            processed += 1
            node_counts = counts[node]
            local_best = max(node_counts)
            if local_best > best:
                best = local_best
            for nxt in adj[node]:
                nxt_counts = counts[nxt]
                nxt_color = ord(colors[nxt]) - 97
                for c in range(26):
                    cand = node_counts[c] + (1 if c == nxt_color else 0)
                    if cand > nxt_counts[c]:
                        nxt_counts[c] = cand
                indegree[nxt] -= 1
                if indegree[nxt] == 0:
                    queue.append(nxt)

        return best if processed == n else -1
```
