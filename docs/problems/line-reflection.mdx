## Problem

Given `n` points on a 2D plane, find if there is such a line parallel to the y-axis that reflects the given points symmetrically.

In other words, answer whether or not if there exists a line that after reflecting all points over the given line, the original points' set is the same as the reflected ones.

**Note** that there can be repeated points.

### Constraints

- `n == points.length`
- `1 <= n <= 10^4`
- `-10^8 <= points[i][j] <= 10^8`

**Follow up:** Could you do better than `O(n^2)`?

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/line_reflection/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/line_reflection/test_solution.py):

```python
class Solution:
    # Time: O(n)
    # Space: O(n)
    def is_reflected(self, points: list[list[int]]) -> bool:
        min_x, max_x = min(x for x, _ in points), max(x for x, _ in points)
        point_set = {(x, y) for x, y in points}
        s = min_x + max_x
        return all((s - x, y) in point_set for x, y in points)
```
