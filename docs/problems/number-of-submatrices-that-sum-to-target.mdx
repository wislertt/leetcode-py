## Problem

Given a &lt;code>matrix&lt;/code>&nbsp;and a &lt;code>target&lt;/code>, return the number of non-empty submatrices that sum to &lt;code>target&lt;/code>.

A submatrix &lt;code>x1, y1, x2, y2&lt;/code> is the set of all cells &lt;code>matrix[x][y]&lt;/code> with &lt;code>x1 &lt;= x &lt;= x2&lt;/code> and &lt;code>y1 &lt;= y &lt;= y2&lt;/code>.

Two submatrices &lt;code>(x1, y1, x2, y2)&lt;/code> and &lt;code>(x1&#39;, y1&#39;, x2&#39;, y2&#39;)&lt;/code> are different if they have some coordinate&nbsp;that is different: for example, if &lt;code>x1 != x1&#39;&lt;/code>.

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/number_of_submatrices_that_sum_to_target/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/number_of_submatrices_that_sum_to_target/test_solution.py):

```python
class Solution:
    # Time: O(rows^2 * cols)
    # Space: O(cols)
    def num_submatrix_sum_target(self, matrix: list[list[int]], target: int) -> int:
        rows, cols = len(matrix), len(matrix[0])
        count = 0
        for top in range(rows):
            col_sums = [0] * cols
            for bottom in range(top, rows):
                for c in range(cols):
                    col_sums[c] += matrix[bottom][c]
                prefix: dict[int, int] = {0: 1}
                running = 0
                for s in col_sums:
                    running += s
                    count += prefix.get(running - target, 0)
                    prefix[running] = prefix.get(running, 0) + 1
        return count
```
