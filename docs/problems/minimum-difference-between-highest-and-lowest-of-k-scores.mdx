## Problem

&lt;p>You are given a &lt;strong>0-indexed&lt;/strong> integer array &lt;code>nums&lt;/code>, where &lt;code>nums[i]&lt;/code> represents the score of the &lt;code>i&lt;sup>th&lt;/sup>&lt;/code> student. You are also given an integer &lt;code>k&lt;/code>.&lt;/p>

&lt;p>Pick the scores of any &lt;code>k&lt;/code> students from the array so that the &lt;strong>difference&lt;/strong> between the &lt;strong>highest&lt;/strong> and the &lt;strong>lowest&lt;/strong> of the &lt;code>k&lt;/code> scores is &lt;strong>minimized&lt;/strong>.&lt;/p>

&lt;p>Return &lt;em>the &lt;strong>minimum&lt;/strong> possible difference&lt;/em>.&lt;/p>

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_difference_between_highest_and_lowest_of_k_scores/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_difference_between_highest_and_lowest_of_k_scores/test_solution.py):

```python
class Solution:
    # Time: O(n log n)
    # Space: O(n) for the sort
    def minimum_difference(self, nums: list[int], k: int) -> int:
        scores = sorted(nums)
        return min(scores[i + k - 1] - scores[i] for i in range(len(scores) - k + 1))
```
