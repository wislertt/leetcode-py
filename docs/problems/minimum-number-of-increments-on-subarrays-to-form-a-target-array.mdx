## Problem

You are given an integer array &lt;code>target&lt;/code>. You have an integer array &lt;code>initial&lt;/code> of the same size as &lt;code>target&lt;/code> with all elements initially zeros.

In one operation you can choose &lt;strong>any&lt;/strong> subarray from &lt;code>initial&lt;/code> and increment each value by one.

Return &lt;em>the minimum number of operations to form a &lt;/em>&lt;code>target&lt;/code>&lt;em> array from &lt;/em>&lt;code>initial&lt;/code>.

The test cases are generated so that the answer fits in a 32-bit integer.

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_number_of_increments_on_subarrays_to_form_a_target_array/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_number_of_increments_on_subarrays_to_form_a_target_array/test_solution.py):

```python
class Solution:
    # Time: O(n)
    # Space: O(1)
    def min_number_operations(self, target: list[int]) -> int:
        operations = 0
        prev = 0
        for value in target:
            if value > prev:
                operations += value - prev
            prev = value
        return operations
```
