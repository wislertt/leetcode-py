## Problem

Given an array of integers `nums` and an integer `k`, return the number of **unique** k-diff pairs in the array.

A **k-diff** pair is an integer pair `(nums[i], nums[j])`, where the following are true:

- `0 <= i, j < nums.length`
- `i != j`
- `|nums[i] - nums[j]| == k`

**Notice** that `|val|` denotes the absolute value of `val`.

### Examples

```
Input: nums = [3,1,4,1,5], k = 2
Output: 2
Explanation: There are two 2-diff pairs in the array, (1, 3) and (3, 5).
Although we have two 1s in the input, we should only return the number of **unique** pairs.
```

```
Input: nums = [1,2,3,4,5], k = 1
Output: 4
Explanation: There are four 1-diff pairs in the array, (1, 2), (2, 3), (3, 4) and (4, 5).
```

```
Input: nums = [1,3,1,5,4], k = 0
Output: 1
Explanation: There is one 0-diff pair in the array, (1, 1).
```

### Constraints

- 1 &lt;= nums.length &lt;= 10^4
- -10^7 &lt;= nums[i] &lt;= 10^7
- 0 &lt;= k &lt;= 10^7

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/k_diff_pairs_in_an_array/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/k_diff_pairs_in_an_array/test_solution.py):

```python
from collections import Counter


class Solution:
    # Time: O(n)
    # Space: O(n)
    def find_pairs(self, nums: list[int], k: int) -> int:
        counts = Counter(nums)
        if k == 0:
            return sum(1 for count in counts.values() if count > 1)
        return sum(1 for value in counts if value + k in counts)
```
