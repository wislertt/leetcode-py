## Problem

&lt;p>Given a binary array &lt;code>nums&lt;/code> and an integer &lt;code>goal&lt;/code>, return &lt;em>the number of non-empty &lt;strong>subarrays&lt;/strong> with a sum&lt;/em> &lt;code>goal&lt;/code>.&lt;/p>

&lt;p>A &lt;strong>subarray&lt;/b> is a contiguous part of the array.&lt;/p>

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/binary_subarrays_with_sum/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/binary_subarrays_with_sum/test_solution.py):

```python
class Solution:
    # Time: O(n)
    # Space: O(n)
    def num_subarrays_with_sum(self, nums: list[int], goal: int) -> int:
        # Prefix sum counts: sum -> number of prefixes with that sum
        prefix_counts: dict[int, int] = {0: 1}
        total = 0
        count = 0
        for num in nums:
            total += num
            count += prefix_counts.get(total - goal, 0)
            prefix_counts[total] = prefix_counts.get(total, 0) + 1
        return count
```
