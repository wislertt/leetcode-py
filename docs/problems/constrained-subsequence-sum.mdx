## Problem

Given an integer array &lt;code>nums&lt;/code> and an integer &lt;code>k&lt;/code>, return the maximum sum of a &lt;strong>non-empty&lt;/strong> subsequence of that array such that for every two &lt;strong>consecutive&lt;/strong> integers in the subsequence, &lt;code>nums[i]&lt;/code> and &lt;code>nums[j]&lt;/code>, where &lt;code>i &lt; j&lt;/code>, the condition &lt;code>j - i &lt;= k&lt;/code> is satisfied.&lt;/p>

&lt;p>A &lt;em>subsequence&lt;/em> of an array is obtained by deleting some number of elements (can be zero) from the array, leaving the remaining elements in their original order.

### Examples

```
Input: nums = [10,2,-10,5,20], k = 2
Output: 37
Explanation: The subsequence is [10, 2, 5, 20].
```

```
Input: nums = [-1,-2,-3], k = 1
Output: -1
Explanation: The subsequence must be non-empty, so we choose the largest number.
```

```
Input: nums = [10,-2,-10,-5,20], k = 2
Output: 23
Explanation: The subsequence is [10, -2, -5, 20].
```

### Constraints

- 1 &lt;= k &lt;= nums.length &lt;= 10^5
- -10^4 &lt;= nums[i] &lt;= 10^4

```python
from collections import deque


class Solution:
    # Time: O(n)
    # Space: O(k)
    def constrained_subset_sum(self, nums: list[int], k: int) -> int:
        dp = [0] * len(nums)
        window = deque()
        for i, num in enumerate(nums):
            dp[i] = num + (dp[window[0]] if window and dp[window[0]] > 0 else 0)
            while window and dp[window[-1]] <= dp[i]:
                window.pop()
            window.append(i)
            if window[0] <= i - k:
                window.popleft()
        return max(dp)
```
