## Problem

Given an integer array &lt;code>nums&lt;/code> and an integer &lt;code>k&lt;/code>, return &lt;em>the length of the shortest non-empty &lt;strong>subarray&lt;/strong> of &lt;/em>&lt;code>nums&lt;/code>&lt;em> with a sum of at least &lt;/em>&lt;code>k&lt;/code>. If there is no such &lt;strong>subarray&lt;/strong>, return &lt;code>-1&lt;/code>.&lt;/p>

&lt;p>A &lt;strong>subarray&lt;/strong> is a &lt;strong>contiguous&lt;/strong> part of an array.

### Examples

```
Input: nums = [1], k = 1
Output: 1
```

```
Input: nums = [1,2], k = 4
Output: -1
```

```
Input: nums = [2,-1,2], k = 3
Output: 3
```

### Constraints

- -10^5 &lt;= nums[i] &lt;= 10^5
- 1 &lt;= k &lt;= 10^9

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/shortest_subarray_with_sum_at_least_k/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/shortest_subarray_with_sum_at_least_k/test_solution.py):

```python
from collections import deque


class Solution:
    # Time: O(n)
    # Space: O(n)
    def shortest_subarray(self, nums: list[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i, num in enumerate(nums):
            prefix[i + 1] = prefix[i] + num
        result = n + 1
        queue: deque[int] = deque()
        for j in range(n + 1):
            while queue and prefix[j] - prefix[queue[0]] >= k:
                result = min(result, j - queue.popleft())
            while queue and prefix[queue[-1]] >= prefix[j]:
                queue.pop()
            queue.append(j)
        return result if result <= n else -1
```
