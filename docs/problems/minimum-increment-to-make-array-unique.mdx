## Problem

&lt;p>You are given an integer array &lt;code>nums&lt;/code>. In one move, you can pick an index &lt;code>i&lt;/code> where &lt;code>0 &lt;= i &lt; nums.length&lt;/code> and increment &lt;code>nums[i]&lt;/code> by &lt;code>1&lt;/code>.&lt;/p>

&lt;p>Return &lt;em>the minimum number of moves to make every value in &lt;/em>&lt;code>nums&lt;/code>&lt;em> &lt;strong>unique&lt;/strong>&lt;/em>.&lt;/p>

&lt;p>The test cases are generated so that the answer fits in a 32-bit integer.&lt;/p>

### Examples

```
Input: nums = [1,2,2]
Output: 1
Explanation: After 1 move, the array could be [1, 2, 3].
```

```
Input: nums = [3,2,1,2,1,7]
Output: 6
Explanation: After 6 moves, the array could be [3, 4, 1, 2, 5, 7].
It can be shown that it is impossible for the array to have all unique values with 5 or less moves.
```

### Constraints

- 1 &lt;= nums.length &lt;= 10^5
- 0 &lt;= nums[i] &lt;= 10^5

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_increment_to_make_array_unique/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_increment_to_make_array_unique/test_solution.py):

```python
class Solution:
    # Time: O(n log n)
    # Space: O(n) for the sorted copy
    def min_increment_for_unique(self, nums: list[int]) -> int:
        moves = 0
        previous = -1
        for num in sorted(nums):
            if num <= previous:
                # Raise num to one above the last placed value
                moves += previous - num + 1
                previous += 1
            else:
                previous = num
        return moves
```
