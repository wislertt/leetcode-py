## Problem

In combinatorial mathematics, a **derangement** is a permutation of the elements of a set, such that no element appears in its original position.

You are given an integer `n`. There is originally an array consisting of `n` integers from `1` to `n` in ascending order, return the number of **derangements** it can generate. Since the answer may be huge, return it **modulo** `10^9 + 7`.

### Examples

```
Input: n = 3
Output: 2
Explanation: The original array is [1,2,3]. The two derangements are [2,3,1] and [3,1,2].
```

```
Input: n = 2
Output: 1
```

### Constraints

- `1 <= n <= 10^6`

```python
class Solution:
    # Time: O(n)
    # Space: O(1)
    def find_derangement(self, n: int) -> int:
        mod = 1_000_000_007
        if n == 1:
            return 0
        a, b = 1, 0  # D(1) = 0 carried via a = D(k-1)
        for k in range(2, n + 1):
            a, b = b, (k - 1) * (a + b) % mod
        return b % mod
```
