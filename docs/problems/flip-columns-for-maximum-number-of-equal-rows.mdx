## Problem

You are given an &lt;code>m x n&lt;/code> binary matrix &lt;code>matrix&lt;/code>.

You can choose any number of columns in the matrix and flip every cell in that column (i.e., Change the value of the cell from &lt;code>0&lt;/code> to &lt;code>1&lt;/code> or vice versa).

Return &lt;em>the maximum number of rows that have all values equal after some number of flips&lt;/em>.

### Examples

```
Input: matrix = [[0,1],[1,1]]
Output: 1
Explanation: After flipping no values, 1 row has all values equal.
```

```
Input: matrix = [[0,1],[1,0]]
Output: 2
Explanation: After flipping values in the first column, both rows have equal values.
```

```
Input: matrix = [[0,0,0],[0,0,1],[1,1,0]]
Output: 2
Explanation: After flipping values in the first two columns, the last two rows have equal values.
```

### Constraints

- &lt;code>m == matrix.length&lt;/code>
- &lt;code>n == matrix[i].length&lt;/code>
- &lt;code>1 &lt;= m, n &lt;= 300&lt;/code>
- &lt;code>matrix[i][j]&lt;/code> is either &lt;code>0&lt;/code> or &lt;code>1&lt;/code>.

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/flip_columns_for_maximum_number_of_equal_rows/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/flip_columns_for_maximum_number_of_equal_rows/test_solution.py):

```python
class Solution:
    # Time: O(m * n)
    # Space: O(m * n)
    def max_equal_rows_after_flips(self, matrix: list[list[int]]) -> int:
        counts: dict[tuple[int, ...], int] = {}
        for row in matrix:
            key = tuple(row) if row[0] == 0 else tuple(1 - x for x in row)
            counts[key] = counts.get(key, 0) + 1
        return max(counts.values())
```
