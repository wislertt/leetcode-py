## Problem

The &lt;a href="https://en.wikipedia.org/wiki/Hamming_distance" target="_blank">Hamming distance&lt;/a> between two integers is the number of positions at which the corresponding bits are different.

Given two integers &lt;code>x&lt;/code> and &lt;code>y&lt;/code>, return &lt;em>the &lt;strong>Hamming distance&lt;/strong> between them&lt;/em>.

### Examples

```
Input: x = 1, y = 4
Output: 2
Explanation:
1   (0 0 0 1)
4   (0 1 0 0)
       ↑   ↑
The above arrows point to positions where the corresponding bits are different.
```

```
Input: x = 3, y = 1
Output: 1
```

### Constraints

- 0 &lt;= x, y &lt;= 2^31 - 1

**Note:** This question is the same as [2220: Minimum Bit Flips to Convert Number](https://leetcode.com/problems/minimum-bit-flips-to-convert-number/description/).

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/hamming_distance/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/hamming_distance/test_solution.py):

```python
class Solution:
    # Time: O(b), b = number of differing bits (<= 31)
    # Space: O(1)
    def hamming_distance(self, x: int, y: int) -> int:
        return (x ^ y).bit_count()
```
