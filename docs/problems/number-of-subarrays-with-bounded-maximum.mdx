## Problem

Given an integer array &lt;code>nums&lt;/code> and two integers &lt;code>left&lt;/code> and &lt;code>right&lt;/code>, return &lt;em>the number of contiguous non-empty &lt;strong>subarrays&lt;/strong> such that the value of the maximum array element in that subarray is in the range&lt;/em> &lt;code>[left, right]&lt;/code>.

The test cases are generated so that the answer will fit in a &lt;strong>32-bit&lt;/strong> integer.

### Examples

```
Input: nums = [2,1,4,3], left = 2, right = 3
Output: 3
Explanation: There are three subarrays that meet the requirements: [2], [2, 1], [3].
```

```

Output: 7
```

- `0 <= nums[i] <= 10^9`
- `0 <= left <= right <= 10^9`

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/number_of_subarrays_with_bounded_maximum/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/number_of_subarrays_with_bounded_maximum/test_solution.py):

```python
class Solution:
    # Time: O(n)
    # Space: O(1)
    def num_subarray_bounded_max(self, nums: list[int], left: int, right: int) -> int:
        def at_most(bound: int) -> int:
            total = 0
            run = 0
            for value in nums:
                run = run + 1 if value <= bound else 0
                total += run
            return total

        return at_most(right) - at_most(left - 1)
```
