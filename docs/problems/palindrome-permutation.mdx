## Problem

Given a string `s`, return `true` *if a permutation of the string could form a **palindrome** and* `false` *otherwise*.

### Examples

```
Input: s = "code"
Output: false
```

```
Input: s = "aab"
Output: true
```

```
Input: s = "carerac"
Output: true
```

### Constraints

- `1 <= s.length <= 5000`
- `s` consists of only lowercase English letters.

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/palindrome_permutation/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/palindrome_permutation/test_solution.py):

```python
from collections import Counter


class Solution:
    # Time: O(n)
    # Space: O(1) for the 26-letter alphabet
    def can_permute_palindrome(self, s: str) -> bool:
        counts = Counter(s)
        return sum(count % 2 for count in counts.values()) < 2
```
