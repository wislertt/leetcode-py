## Problem

&lt;p>You are given an integer array &lt;code>nums&lt;/code>.&lt;/p>

&lt;p>In one move, you can choose one element of &lt;code>nums&lt;/code> and change it to &lt;strong>any value&lt;/strong>.&lt;/p>

&lt;p>Return &lt;em>the minimum difference between the largest and smallest value of &lt;/em>&lt;code>nums&lt;/code>&lt;em> &lt;strong>after performing at most three moves&lt;/strong>&lt;/em>.&lt;/p>

### Examples

```
Input: nums = [5,3,2,4]
Output: 0
Explanation: We can make at most 3 moves.
In the first move, change 2 to 3. nums becomes [5,3,3,4].
In the second move, change 4 to 3. nums becomes [5,3,3,3].
In the third move, change 5 to 3. nums becomes [3,3,3,3].
After performing 3 moves, the difference between the minimum and maximum is 3 - 3 = 0.
```

```
Input: nums = [1,5,0,10,14]
Output: 1
Explanation: We can make at most 3 moves.
In the first move, change 5 to 0. nums becomes [1,0,0,10,14].
In the second move, change 10 to 0. nums becomes [1,0,0,0,14].
In the third move, change 14 to 1. nums becomes [1,0,0,0,1].
After performing 3 moves, the difference between the minimum and maximum is 1 - 0 = 1.
It can be shown that there is no way to make the difference 0 in 3 moves.
```

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_difference_between_largest_and_smallest_value_in_three_moves/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_difference_between_largest_and_smallest_value_in_three_moves/test_solution.py):

```python
class Solution:
    # Time: O(n log n)
    # Space: O(n) for the sort
    def min_difference(self, nums: list[int]) -> int:
        if len(nums) <= 4:
            return 0
        nums = sorted(nums)
        return min(nums[-4 + i] - nums[i] for i in range(4))
```
