## Problem

&lt;p>You are given &lt;code>nums&lt;/code>, an array of positive integers of size &lt;code>2 * n&lt;/code>. You must perform &lt;code>n&lt;/code> operations on this array.&lt;/p>

&lt;p>In the &lt;code>i&lt;sup>th&lt;/sup>&lt;/code> operation &lt;strong>(1-indexed)&lt;/strong>, you will:&lt;/p>

&lt;ul>
	&lt;li>Choose two elements, &lt;code>x&lt;/code> and &lt;code>y&lt;/code>.&lt;/li>
	&lt;li>Receive a score of &lt;code>i * gcd(x, y)&lt;/code>.&lt;/li>
	&lt;li>Remove &lt;code>x&lt;/code> and &lt;code>y&lt;/code> from &lt;code>nums&lt;/code>.&lt;/li>
&lt;/ul>

&lt;p>Return &lt;em>the maximum score you can receive after performing &lt;/em>&lt;code>n&lt;/code>&lt;em> operations.&lt;/em>&lt;/p>

&lt;p>The function &lt;code>gcd(x, y)&lt;/code> is the greatest common divisor of &lt;code>x&lt;/code> and &lt;code>y&lt;/code>.&lt;/p>

### Examples

```
Input: nums = [1,2]
Output: 1
Explanation: The optimal choice of operations is:
(1 * gcd(1, 2)) = 1
```

```
Input: nums = [3,4,6,8]
Output: 11
Explanation: The optimal choice of operations is:
(1 * gcd(3, 6)) + (2 * gcd(4, 8)) = 3 + 8 = 11
```

```
Input: nums = [1,2,3,4,5,6]
Output: 14
Explanation: The optimal choice of operations is:
(1 * gcd(1, 5)) + (2 * gcd(2, 4)) + (3 * gcd(3, 6)) = 1 + 4 + 9 = 14
```

### Constraints

- 1 &lt;= n &lt;= 7
- nums.length == 2 * n
- 1 &lt;= nums[i] &lt;= 10^6

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/maximize_score_after_n_operations/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/maximize_score_after_n_operations/test_solution.py):

```python
from math import gcd


class Solution:
    # Time: O(2^m * m^2) where m = len(nums) = 2n <= 14
    # Space: O(2^m)
    def max_score(self, nums: list[int]) -> int:
        m = len(nums)
        gcd_table = [[0] * m for _ in range(m)]
        for i in range(m):
            for j in range(i + 1, m):
                gcd_table[i][j] = gcd_table[j][i] = gcd(nums[i], nums[j])

        full = (1 << m) - 1
        dp = [0] * (1 << m)
        for mask in range(full):
            op = mask.bit_count() // 2 + 1
            for i in range(m):
                if mask >> i & 1:
                    continue
                for j in range(i + 1, m):
                    if mask >> j & 1:
                        continue
                    nxt = mask | 1 << i | 1 << j
                    dp[nxt] = max(dp[nxt], dp[mask] + op * gcd_table[i][j])
        return dp[full]
```
