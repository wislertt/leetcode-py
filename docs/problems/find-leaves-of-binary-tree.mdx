## Problem

Given the `root` of a binary tree, collect a tree's nodes as if you were doing this:

- Collect all the leaf nodes.
- Remove all the leaf nodes.
- Repeat until the tree is empty.

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/find_leaves_of_binary_tree/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/find_leaves_of_binary_tree/test_solution.py):

```python
from leetcode_py import TreeNode


class Solution:
    # Time: O(n) — every node visited once
    # Space: O(h) — recursion depth equals tree height
    def find_leaves(self, root: TreeNode[int] | None) -> list[list[int]]:
        result: list[list[int]] = []

        def height(node: TreeNode[int] | None) -> int:
            if node is None:
                return 0
            h = 1 + max(height(node.left), height(node.right))
            while len(result) < h:
                result.append([])
            result[h - 1].append(node.val)
            return h

        height(root)
        return result
```
