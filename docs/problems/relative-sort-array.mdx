## Problem

Given two arrays &lt;code>arr1&lt;/code> and &lt;code>arr2&lt;/code>, the elements of &lt;code>arr2&lt;/code> are distinct, and all elements in &lt;code>arr2&lt;/code> are also in &lt;code>arr1&lt;/code>.

Sort the elements of &lt;code>arr1&lt;/code> such that the relative ordering of items in &lt;code>arr1&lt;/code> are the same as in &lt;code>arr2&lt;/code>. Elements that do not appear in &lt;code>arr2&lt;/code> should be placed at the end of &lt;code>arr1&lt;/code> in &lt;strong>ascending&lt;/strong> order.

### Examples

```
Input: arr1 = [2,3,1,3,2,4,6,7,9,2,19], arr2 = [2,1,4,3,9,6]
Output: [2,2,2,1,4,3,3,9,6,7,19]
```

```
Input: arr1 = [28,6,22,8,44,17], arr2 = [22,28,8,6]
Output: [22,28,8,6,17,44]
```

### Constraints

- &lt;code>1 &lt;= arr1.length, arr2.length &lt;= 1000&lt;/code>
- &lt;code>0 &lt;= arr1[i], arr2[i] &lt;= 1000&lt;/code>
- All the elements of &lt;code>arr2&lt;/code> are &lt;strong>distinct&lt;/strong>.
- Each&nbsp;&lt;code>arr2[i]&lt;/code> is in &lt;code>arr1&lt;/code>.

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/relative_sort_array/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/relative_sort_array/test_solution.py):

```python
class Solution:
    # Time: O(n log n)
    # Space: O(n)
    def relative_sort_array(self, arr1: list[int], arr2: list[int]) -> list[int]:
        rank = {v: i for i, v in enumerate(arr2)}
        present = sorted((x for x in arr1 if x in rank), key=lambda x: rank[x])
        rest = sorted(x for x in arr1 if x not in rank)
        return present + rest
```
