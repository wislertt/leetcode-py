## Problem

Your task is to calculate a&lt;sup>b&lt;/sup> mod 1337 where `a` is a positive integer and `b` is an extremely large positive integer given in the form of an array.

### Examples

```
Input: a = 2, b = [3]
Output: 8
```

```
Input: a = 2, b = [1,0]
Output: 1024
```

```
Input: a = 1, b = [4,3,3,8,5,2]
Output: 1
```

### Constraints

- 1 &lt;= a &lt;= 2^31 - 1
- 1 &lt;= b.length &lt;= 2000
- 0 &lt;= b[i] &lt;= 9
- `b` does not contain leading zeros.

```python
class Solution:
    # Time: O(n) where n = len(b)
    # Space: O(1)
    def super_pow(self, a: int, b: list[int]) -> int:
        mod = 1337
        result = 1
        a %= mod
        for digit in b:
            result = (pow(result, 10, mod) * pow(a, digit, mod)) % mod
        return result
```
