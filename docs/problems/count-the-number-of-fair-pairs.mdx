## Problem

Given a &lt;strong>0-indexed&lt;/strong> integer array &lt;code>nums&lt;/code> of size &lt;code>n&lt;/code> and two integers &lt;code>lower&lt;/code> and &lt;code>upper&lt;/code>, return &lt;em>the number of &lt;strong>fair pairs&lt;/strong>&lt;/em>.

A pair &lt;code>(i, j)&lt;/code> is &lt;strong>fair&lt;/strong> if:

&lt;ul>
&lt;li>&lt;code>0 &lt;= i &lt; j &lt; n&lt;/code>, and&lt;/li>
&lt;li>&lt;code>lower &lt;= nums[i] + nums[j] &lt;= upper&lt;/code>&lt;/li>
&lt;/ul>

### Examples

```
Input: nums = [0,1,7,4,4,5], lower = 3, upper = 6
Output: 6
```
**Explanation:** There are 6 fair pairs: (0,3), (0,4), (0,5), (1,3), (1,4), and (1,5).

```
Input: nums = [1,7,9,2,5], lower = 11, upper = 11
Output: 1
```
**Explanation:** There is a single fair pair: (2,3).

### Constraints

- 1 &lt;= nums.length &lt;= 10^5
- nums.length == n
- -10^9 &lt;= nums[i] &lt;= 10^9
- -10^9 &lt;= lower &lt;= upper &lt;= 10^9

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/count_the_number_of_fair_pairs/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/count_the_number_of_fair_pairs/test_solution.py):

```python
class Solution:
    # Time: O(n log n)
    # Space: O(n) for the sort
    def count_fair_pairs(self, nums: list[int], lower: int, upper: int) -> int:
        nums.sort()

        def count_at_most(bound: int) -> int:
            left, right = 0, len(nums) - 1
            total = 0
            while left < right:
                if nums[left] + nums[right] <= bound:
                    total += right - left
                    left += 1
                else:
                    right -= 1
            return total

        return count_at_most(upper) - count_at_most(lower - 1)
```
