## Problem

A positive integer is magical if it is divisible by either `a` or `b`.

Given the three integers `n`, `a`, and `b`, return the nth magical number. Since the answer may be very large, return it modulo `10^9 + 7`.

### Examples

```
Input: n = 1, a = 2, b = 3
Output: 2
```

```
Input: n = 4, a = 2, b = 3
Output: 6
```

### Constraints

- 1 &lt;= n &lt;= 10^9
- 2 &lt;= a, b &lt;= 4 * 10^4

**Follow up:** Could you solve the problem in `O(log(n * min(a, b)))` time complexity?

```python
from math import gcd


class Solution:
    # Time: O(log(n * min(a, b)))
    # Space: O(1)
    def nth_magical_number(self, n: int, a: int, b: int) -> int:
        mod = 10**9 + 7
        lcm = a * b // gcd(a, b)

        def count(x: int) -> int:
            return x // a + x // b - x // lcm

        low, high = 1, n * min(a, b)
        while low < high:
            mid = (low + high) // 2
            if count(mid) >= n:
                high = mid
            else:
                low = mid + 1
        return low % mod
```
