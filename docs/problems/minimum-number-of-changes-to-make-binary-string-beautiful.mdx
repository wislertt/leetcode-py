## Problem

&lt;p>You are given a &lt;strong>0-indexed&lt;/strong> binary string &lt;code>s&lt;/code> having an even length.&lt;/p>

&lt;p>A string is &lt;strong>beautiful&lt;/strong> if it&#39;s possible to partition it into one or more substrings such that:&lt;/p>

&lt;ul>
	&lt;li>Each substring has an &lt;strong>even length&lt;/strong>.&lt;/li>
	&lt;li>Each substring contains &lt;strong>only&lt;/strong> &lt;code>1&lt;/code>&#39;s or &lt;strong>only&lt;/strong> &lt;code>0&lt;/code>&#39;s.&lt;/li>
&lt;/ul>

&lt;p>You can change any character in &lt;code>s&lt;/code> to &lt;code>0&lt;/code> or &lt;code>1&lt;/code>.&lt;/p>

&lt;p>Return &lt;em>the &lt;strong>minimum&lt;/strong> number of changes required to make the string &lt;/em>&lt;code>s&lt;/code> &lt;em>beautiful&lt;/em>.&lt;/p>

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_number_of_changes_to_make_binary_string_beautiful/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_number_of_changes_to_make_binary_string_beautiful/test_solution.py):

```python
class Solution:
    # Time: O(n)
    # Space: O(1)
    def min_changes(self, s: str) -> int:
        # Every substring has even length, so each pair (s[2i], s[2i+1]) must
        # be uniform; aligning each pair to its majority character is optimal.
        changes = 0
        for i in range(0, len(s), 2):
            if s[i] != s[i + 1]:
                changes += 1
        return changes
```
