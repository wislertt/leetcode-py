## Problem

You are given an n x n integer matrix grid.

Generate an integer matrix maxLocal of size (n - 2) x (n - 2) such that:

- maxLocal[i][j] is equal to the largest value of the 3 x 3 matrix in grid centered around row i + 1 and column j + 1.

In other words, we want to find the largest value in every contiguous 3 x 3 matrix in grid.

Return the generated matrix.

- n == grid.length == grid[i].length
- 3 &lt;= n &lt;= 100
- 1 &lt;= grid[i][j] &lt;= 100

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/largest_local_values_in_a_matrix/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/largest_local_values_in_a_matrix/test_solution.py):

```python
class Solution:
    # Time: O(n^2) - each of the (n - 2)^2 windows scans a fixed 3 x 3 area
    # Space: O(1) extra - excluding the (n - 2) x (n - 2) output matrix
    def largest_local(self, grid: list[list[int]]) -> list[list[int]]:
        n = len(grid)
        return [
            [max(grid[i + a][j + b] for a in range(3) for b in range(3)) for j in range(n - 2)]
            for i in range(n - 2)
        ]
```
