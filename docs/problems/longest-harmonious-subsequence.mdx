## Problem

We define a harmonious array as an array where the difference between its maximum value and its minimum value is **exactly** `1`.

Given an integer array `nums`, return the length of its longest harmonious subsequence among all its possible subsequences.

### Examples

```
Input: nums = [1,3,2,2,5,2,3,7]
Output: 5
Explanation: The longest harmonious subsequence is [3,2,2,2,3].
```

```
Input: nums = [1,2,3,4]
Output: 2
Explanation: The longest harmonious subsequences are [1,2], [2,3], and [3,4], all of which have a length of 2.
```

```
Input: nums = [1,1,1,1]
Output: 0
Explanation: No harmonious subsequence exists.
```

### Constraints

- 1 &lt;= nums.length &lt;= 2 * 10^4
- -10^9 &lt;= nums[i] &lt;= 10^9

```python
from collections import Counter


class Solution:
    # Time: O(n)
    # Space: O(n)
    def find_lhs(self, nums: list[int]) -> int:
        counts = Counter(nums)
        longest = 0
        for value, count in counts.items():
            if value + 1 in counts:
                longest = max(longest, count + counts[value + 1])
        return longest
```
