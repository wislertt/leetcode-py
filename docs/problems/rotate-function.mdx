## Problem

You are given an integer array `nums` of length `n`.

Assume `arrk` to be an array obtained by rotating `nums` by `k` positions clock-wise. We define the **rotation function** `F` on `nums` as follow:

- `F(k) = 0 * arrk[0] + 1 * arrk[1] + ... + (n - 1) * arrk[n - 1].`

Return *the maximum value of* `F(0), F(1), ..., F(n-1)`.

The test cases are generated so that the answer fits in a **32-bit** integer.

### Examples

```
Input: nums = [4,3,2,6]
Output: 26
```
**Explanation:**
F(0) = (0 * 4) + (1 * 3) + (2 * 2) + (3 * 6) = 0 + 3 + 4 + 18 = 25
F(1) = (0 * 6) + (1 * 4) + (2 * 3) + (3 * 2) = 0 + 4 + 6 + 6 = 16
F(2) = (0 * 2) + (1 * 6) + (2 * 4) + (3 * 3) = 0 + 6 + 8 + 9 = 23
F(3) = (0 * 3) + (1 * 2) + (2 * 6) + (3 * 4) = 0 + 2 + 12 + 12 = 26
So the maximum value of F(0), F(1), F(2), F(3) is F(3) = 26.

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/rotate_function/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/rotate_function/test_solution.py):

```python
class Solution:
    # Time: O(n)
    # Space: O(1)
    def max_rotate_function(self, nums: list[int]) -> int:
        total = sum(nums)
        cur = sum(i * v for i, v in enumerate(nums))
        best = cur
        for k in range(1, len(nums)):
            # rotating clockwise by k moves the last element of arr_(k-1) to index 0
            # and adds total to every other index: F(k) = F(k-1) + total - n * nums[n - k]
            cur += total - len(nums) * nums[-k]
            best = max(best, cur)
        return best
```
