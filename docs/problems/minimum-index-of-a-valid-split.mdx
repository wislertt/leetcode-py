## Problem

An element &lt;code>x&lt;/code> of an integer array &lt;code>arr&lt;/code> of length &lt;code>m&lt;/code> is &lt;strong>dominant&lt;/strong> if &lt;strong>more than half&lt;/strong> the elements of &lt;code>arr&lt;/code> have a value of &lt;code>x&lt;/code>.&lt;/p>

&lt;p>You are given a &lt;strong>0-indexed&lt;/strong> integer array &lt;code>nums&lt;/code> of length &lt;code>n&lt;/code> with one &lt;strong>dominant&lt;/strong> element.&lt;/p>

&lt;p>You can split &lt;code>nums&lt;/code> at an index &lt;code>i&lt;/code> into two arrays &lt;code>nums[0, ..., i]&lt;/code> and &lt;code>nums[i + 1, ..., n - 1]&lt;/code>, but the split is only &lt;strong>valid&lt;/strong> if:&lt;/p>

&lt;ul>
	&lt;li>&lt;code>0 &lt;= i &lt; n - 1&lt;/code>&lt;/li>
	&lt;li>&lt;code>nums[0, ..., i]&lt;/code>, and &lt;code>nums[i + 1, ..., n - 1]&lt;/code> have the same dominant element.&lt;/li>
&lt;/ul>

&lt;p>Here, &lt;code>nums[i, ..., j]&lt;/code> denotes the subarray of &lt;code>nums&lt;/code> starting at index &lt;code>i&lt;/code> and ending at index &lt;code>j&lt;/code>, both ends being inclusive. Particularly, if &lt;code>j &lt; i&lt;/code> then &lt;code>nums[i, ..., j]&lt;/code> denotes an empty subarray.&lt;/p>

&lt;p>Return &lt;em>the &lt;strong>minimum&lt;/strong> index of a &lt;strong>valid split&lt;/strong>&lt;/em>. If no valid split exists, return &lt;code>-1&lt;/code>.&lt;/p>

### Examples

```
Input: nums = [1,2,2,2]
Output: 2
Explanation: We can split the array at index 2 to obtain arrays [1,2,2] and [2].
In array [1,2,2], element 2 is dominant since it occurs twice in the array and 2 * 2 > 3.
In array [2], element 2 is dominant since it occurs once in the array and 1 * 2 > 1.
Both [1,2,2] and [2] have the same dominant element as nums, so this is a valid split.
It can be shown that index 2 is the minimum index of a valid split.
```

```
Input: nums = [2,1,3,1,1,1,7,1,2,1]
Output: 4
Explanation: We can split the array at index 4 to obtain arrays [2,1,3,1,1] and [1,7,1,2,1].
In array [2,1,3,1,1], element 1 is dominant since it occurs thrice in the array and 3 * 2 > 5.
In array [1,7,1,2,1], element 1 is dominant since it occurs thrice in the array and 3 * 2 > 5.
Both [2,1,3,1,1] and [1,7,1,2,1] have the same dominant element as nums, so this is a valid split.
It can be shown that index 4 is the minimum index of a valid split.
```


### Constraints

- 1 &lt;= nums.length &lt;= 10^5
- 1 &lt;= nums[i] &lt;= 10^9
- nums has exactly one dominant element.

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_index_of_a_valid_split/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/minimum_index_of_a_valid_split/test_solution.py):

```python
class Solution:
    # Time: O(n)
    # Space: O(1)
    def minimum_index(self, nums: list[int]) -> int:
        dominant = 0
        count = 0
        for num in nums:
            if count == 0:
                dominant = num
                count = 1
            elif num == dominant:
                count += 1
            else:
                count -= 1

        total = 0
        for num in nums:
            if num == dominant:
                total += 1

        left = 0
        for i, num in enumerate(nums):
            if num == dominant:
                left += 1
            right = total - left
            if left * 2 > i + 1 and right * 2 > len(nums) - i - 1:
                return i
        return -1
```
