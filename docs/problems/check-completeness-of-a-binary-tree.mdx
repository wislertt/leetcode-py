## Problem

&lt;p>Given the &lt;code>root&lt;/code> of a binary tree, determine if it is a &lt;em>complete binary tree&lt;/em>.&lt;/p>

&lt;p>In a &lt;strong>&lt;a href="http://en.wikipedia.org/wiki/Binary_tree#Types_of_binary_trees" target="_blank">complete binary tree&lt;/a>&lt;/strong>, every level, except possibly the last, is completely filled, and all nodes in the last level are as far left as possible. It can have between &lt;code>1&lt;/code> and &lt;code>2&lt;sup>h&lt;/sup>&lt;/code> nodes inclusive at the last level &lt;code>h&lt;/code>.&lt;/p>

### Examples

![Example 1](https://assets.leetcode.com/uploads/2018/12/15/complete-binary-tree-1.png)

```
Input: root = [1,2,3,4,5,6]
Output: true
Explanation: Every level before the last is full (ie. levels with node-values {1} and {2, 3}), and all nodes in the last level ({4, 5, 6}) are as far left as possible.
```

![Example 2](https://assets.leetcode.com/uploads/2018/12/15/complete-binary-tree-2.png)

```
Input: root = [1,2,3,4,5,null,7]
Output: false
Explanation: The node with value 7 isn't as far left as possible.
```

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/check_completeness_of_a_binary_tree/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/check_completeness_of_a_binary_tree/test_solution.py):

```python
from collections import deque

from leetcode_py import TreeNode


class Solution:
    # Time: O(n)
    # Space: O(n)
    def is_complete_tree(self, root: TreeNode[int] | None) -> bool:
        if root is None:
            return True
        queue: deque[TreeNode[int] | None] = deque([root])
        seen_hole = False
        while queue:
            node = queue.popleft()
            if node is None:
                seen_hole = True
                continue
            if seen_hole:
                # A node appeared after a gap: not complete
                return False
            queue.append(node.left)
            queue.append(node.right)
        return True
```
