## Problem

You have &lt;code>n&lt;/code>&nbsp;&nbsp;&lt;code>tiles&lt;/code>, where each tile has one letter &lt;code>tiles[i]&lt;/code> printed on it.

Return &lt;em>the number of possible non-empty sequences of letters&lt;/em> you can make using the letters printed on those &lt;code>tiles&lt;/code>.

### Examples

```
Input: tiles = "AAB"
Output: 8

```

```

```

### Constraints

- &lt;code>1 &lt;= tiles.length &lt;= 7&lt;/code>

```python
class Solution:
    # Time: O(n!) bounded by distinct-letter tree size
    # Space: O(n)
    def num_tile_possibilities(self, tiles: str) -> int:
        counts: dict[str, int] = {}
        for ch in tiles:
            counts[ch] = counts.get(ch, 0) + 1

        def dfs() -> int:
            total = 0
            for ch in counts:
                if counts[ch] == 0:
                    continue
                counts[ch] -= 1
                total += 1 + dfs()
                counts[ch] += 1
            return total

        return dfs()
```
