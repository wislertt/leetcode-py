## Problem

Given an integer &lt;code>n&lt;/code>, return &lt;em>the number of trailing zeroes in &lt;/em>&lt;code>n!&lt;/code>.

&lt;p>Note that &lt;code>n! = n * (n - 1) * (n - 2) * ... * 3 * 2 * 1&lt;/code>.&lt;/p>

### Examples

```
Input: n = 3
Output: 0
Explanation: 3! = 6, no trailing zero.
```

```
Input: n = 5
Output: 1
Explanation: 5! = 120, one trailing zero.
```

```
Input: n = 0
Output: 0
```

### Constraints

- 0 &lt;= n &lt;= 10^4

&lt;p>&lt;strong>Follow up:&lt;/strong> Could you write a solution that works in logarithmic time complexity?&lt;/p>

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/factorial_trailing_zeroes/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/factorial_trailing_zeroes/test_solution.py):

```python
class Solution:
    # Time: O(log n) (base 5)
    # Space: O(1)
    def trailing_zeroes(self, n: int) -> int:
        zero_count = 0
        while n > 0:
            n //= 5
            zero_count += n
        return zero_count
```
