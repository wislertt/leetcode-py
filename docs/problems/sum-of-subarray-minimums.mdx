## Problem

Given an array of integers &lt;code>arr&lt;/code>, find the sum of &lt;code>min(b)&lt;/code>, where &lt;code>b&lt;/code> ranges over every (contiguous) subarray of &lt;code>arr&lt;/code>. Since the answer may be large, return the answer &lt;strong>modulo&lt;/strong> &lt;code>10&lt;sup>9&lt;/sup> + 7&lt;/code>.

### Examples

```
Input: arr = [3,1,2,4]
Output: 17
Explanation:
Subarrays are [3], [1], [2], [4], [3,1], [1,2], [2,4], [3,1,2], [1,2,4], [3,1,2,4].
Minimums are 3, 1, 2, 4, 1, 1, 2, 1, 1, 1. Sum is 17.
```

```
Input: arr = [50]
Output: 50
```

### Constraints

- 1 &lt;= arr.length &lt;= 3 * 10^4
- 1 &lt;= arr[i] &lt;= 3 * 10^4

```python
class Solution:
    # Time: O(n)
    # Space: O(n)
    def sum_subarray_mins(self, arr: list[int]) -> int:
        mod = 1_000_000_007
        n = len(arr)
        stack: list[int] = []
        prev = [0] * n
        for i, value in enumerate(arr):
            while stack and arr[stack[-1]] >= value:
                stack.pop()
            prev[i] = stack[-1] if stack else -1
            stack.append(i)
        stack.clear()
        next_ = [0] * n
        for i in range(n - 1, -1, -1):
            while stack and arr[stack[-1]] > arr[i]:
                stack.pop()
            next_[i] = stack[-1] if stack else n
            stack.append(i)
        return sum(value * (i - prev[i]) * (next_[i] - i) for i, value in enumerate(arr)) % mod
```
