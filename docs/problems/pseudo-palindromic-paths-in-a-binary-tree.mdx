## Problem

Given a binary tree where node values are digits from 1 to 9 only. A path in the binary tree is said to be **pseudo-palindromic** if at least one permutation of the node values in the path is a palindrome.

Return the number of **pseudo-palindromic** paths going from the root node to leaf nodes.

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/pseudo_palindromic_paths_in_a_binary_tree/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/pseudo_palindromic_paths_in_a_binary_tree/test_solution.py):

```python
from leetcode_py import TreeNode


class Solution:
    # Time: O(n)
    # Space: O(h)
    def pseudo_palindromic_paths(self, root: TreeNode[int] | None) -> int:
        if root is None:
            return 0
        total = 0
        stack: list[tuple[TreeNode[int], int]] = [(root, 1 << root.val)]
        while stack:
            node, mask = stack.pop()
            if node.left is None and node.right is None:
                if mask & (mask - 1) == 0:
                    total += 1
                continue
            if node.left is not None:
                stack.append((node.left, mask ^ (1 << node.left.val)))
            if node.right is not None:
                stack.append((node.right, mask ^ (1 << node.right.val)))
        return total
```
