## Problem

A tree rooted at node 0 is given as follows:

&lt;ul>
	&lt;li>The number of nodes is &lt;code>nodes&lt;/code>;&lt;/li>
	&lt;li>The value of the &lt;code>i&lt;sup>th&lt;/sup>&lt;/code> node is &lt;code>value[i]&lt;/code>;&lt;/li>
	&lt;li>The parent of the &lt;code>i&lt;sup>th&lt;/sup>&lt;/code> node is &lt;code>parent[i]&lt;/code>.&lt;/li>
&lt;/ul>

&lt;p>Remove every subtree whose sum of values of nodes is zero.&lt;/p>

&lt;p>Return &lt;em>the number of the remaining nodes in the tree&lt;/em>.&lt;/p>

### Constraints

- 1 &lt;= nodes &lt;= 10^4
- parent.length == nodes
- 0 &lt;= parent[i] &lt;= nodes - 1
- parent[0] == -1 which indicates that 0 is the root.
- value.length == nodes
- -10^5 &lt;= value[i] &lt;= 10^5
- The given input is &lt;strong>guaranteed&lt;/strong> to represent a &lt;strong>valid tree&lt;/strong>.

```python
class Solution:
    # Time: O(nodes)
    # Space: O(nodes)
    def delete_tree_nodes(self, nodes: int, parent: list[int], value: list[int]) -> int:
        children: list[list[int]] = [[] for _ in range(nodes)]
        for i in range(1, nodes):
            children[parent[i]].append(i)

        # Iterative post-order keeps deep chains within the recursion limit.
        subtree_sums = [0] * nodes
        subtree_counts = [0] * nodes
        stack: list[tuple[int, bool]] = [(0, False)]
        while stack:
            node, processed = stack.pop()
            if processed:
                total, count = value[node], 1
                for child in children[node]:
                    total += subtree_sums[child]
                    count += subtree_counts[child]
                if total == 0:
                    count = 0
                subtree_sums[node], subtree_counts[node] = total, count
            else:
                stack.append((node, True))
                stack.extend((child, False) for child in children[node])
        return subtree_counts[0]
```
