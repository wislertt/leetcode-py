## Problem

&lt;p>You are given the array &lt;code>nums&lt;/code> consisting of &lt;code>n&lt;/code> positive integers. You computed the sum of all non-empty continuous subarrays from the array and then sorted them in non-decreasing order, creating a new array of &lt;code>n * (n + 1) / 2&lt;/code> numbers.&lt;/p>

&lt;p>&lt;em>Return the sum of the numbers from index &lt;/em>&lt;code>left&lt;/code>&lt;em> to index &lt;/em>&lt;code>right&lt;/code> (&lt;strong>indexed from 1&lt;/strong>)&lt;em>, inclusive, in the new array. &lt;/em>Since the answer can be a huge number return it modulo &lt;code>10&lt;sup>9&lt;/sup> + 7&lt;/code>.&lt;/p>

### Examples

Output: 13
Explanation: All subarray sums are 1, 3, 6, 10, 2, 5, 9, 3, 7, 4. After sorting them in non-decreasing order we have the new array [1, 2, 3, 3, 4, 5, 6, 7, 9, 10]. The sum of the numbers from index le = 1 to ri = 5 is 1 + 2 + 3 + 3 + 4 = 13.

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/range_sum_of_sorted_subarray_sums/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/range_sum_of_sorted_subarray_sums/test_solution.py):

```python
class Solution:
    # Time: O(n * log(sum(nums))) ~ O(n log n)
    # Space: O(1)
    def range_sum(self, nums: list[int], n: int, left: int, right: int) -> int:
        mod = 1_000_000_007

        def count_and_sum(target: int) -> tuple[int, int]:
            # Number of subarrays with sum <= target, plus the sum of those sums.
            count = 0
            total = 0
            window_sum = 0
            window_total = 0
            start = 0
            for end, value in enumerate(nums):
                window_sum += value
                window_total += value * (end - start + 1)
                while window_sum > target:
                    window_total -= window_sum
                    window_sum -= nums[start]
                    start += 1
                count += end - start + 1
                total += window_total
            return count, total

        def prefix_sum_of_sums(k: int) -> int:
            # Sum of the k smallest subarray sums.
            lo, hi = min(nums), sum(nums)
            while lo < hi:
                mid = (lo + hi) // 2
                count, _ = count_and_sum(mid)
                if count < k:
                    lo = mid + 1
                else:
                    hi = mid
            count, total = count_and_sum(lo)
            return total - lo * (count - k)

        return (prefix_sum_of_sums(right) - prefix_sum_of_sums(left - 1)) % mod
```
