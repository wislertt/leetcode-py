## Problem

A company is planning to interview `2n` people. Given the array `costs` where `costs[i] = [aCosti, bCosti]`, the cost of flying the `ith` person to city `a` is `aCosti`, and the cost of flying the `ith` person to city `b` is `bCosti`.

Return *the minimum cost to fly every person to a city* such that exactly `n` people arrive in each city.

### Constraints

- `2 * n == costs.length`
- `2 <= costs.length <= 100`
- `costs.length` is even.
- `1 <= aCosti, bCosti <= 1000`

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/two_city_scheduling/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/two_city_scheduling/test_solution.py):

```python
class Solution:
    # Time: O(n log n)
    # Space: O(n) for the sorted copy
    def two_city_sched_cost(self, costs: list[list[int]]) -> int:
        ordered = sorted(costs, key=lambda cost: cost[0] - cost[1])
        n = len(ordered) // 2
        return sum(cost[0] for cost in ordered[:n]) + sum(cost[1] for cost in ordered[n:])
```
