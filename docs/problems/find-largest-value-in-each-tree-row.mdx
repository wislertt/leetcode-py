## Problem

Given the `root` of a binary tree, return *an array of the largest value in each row* of the tree **(0-indexed)**.

### Examples

![Example 1](https://assets.leetcode.com/uploads/2020/08/21/largest_e1.jpg)

```
Input: root = [1,3,2,5,3,null,9]
Output: [1,3,9]
```

```
Input: root = [1,2,3]
Output: [1,3]
```

### Constraints

- The number of nodes in the tree will be in the range `[0, 10^4]`.
- `-2^31 <= Node.val <= 2^31 - 1`

## Solution

Reference implementation from [solution.py on GitHub](https://github.com/wislertt/leetcode-py/blob/main/leetcode/find_largest_value_in_each_tree_row/solution.py), full suite in [test_solution.py](https://github.com/wislertt/leetcode-py/blob/main/leetcode/find_largest_value_in_each_tree_row/test_solution.py):

```python
from collections import deque

from leetcode_py import TreeNode


class Solution:
    # Time: O(n)
    # Space: O(n)
    def largest_values(self, root: TreeNode[int] | None) -> list[int]:
        if root is None:
            return []

        result: list[int] = []
        queue: deque[TreeNode[int]] = deque([root])
        while queue:
            result.append(max(node.val for node in queue))
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        return result
```
