# Base 7

**Difficulty:** Easy
**Topics:** Math, String
**Tags:**

**LeetCode:** [Problem 504](https://leetcode.com/problems/base-7/description/)

## Problem Description

Given an integer `num`, return a string of its base 7 representation.

## Examples

### Example 1:

```
Input: num = 100
Output: "202"
```

### Example 2:

```
Input: num = -7
Output: "-10"
```

## Constraints

- -10^7 <= num <= 10^7
