# Palindrome Permutation

**Difficulty:** Easy
**Topics:** Bit Manipulation, Hash Table, String
**Tags:** neetcode

**LeetCode:** [Problem 266](https://leetcode.com/problems/palindrome-permutation/description/)

## Problem Description

Given a string `s`, return `true` _if a permutation of the string could form a **palindrome** and_ `false` _otherwise_.

## Examples

### Example 1:

```
Input: s = "code"
Output: false
```

### Example 2:

```
Input: s = "aab"
Output: true
```

### Example 3:

```
Input: s = "carerac"
Output: true
```

## Constraints

- `1 <= s.length <= 5000`
- `s` consists of only lowercase English letters.
