# Remove Duplicates from Sorted List

**Difficulty:** Easy
**Topics:** Linked List
**Tags:** neetcode

**LeetCode:** [Problem 83](https://leetcode.com/problems/remove-duplicates-from-sorted-list/description/)

## Problem Description

Given the `head` of a sorted linked list, _delete all duplicates such that each element appears only once_. Return the linked list **sorted** as well.

## Examples

### Example 1:

![Example 1](https://assets.leetcode.com/uploads/2021/01/04/list1.jpg)

```
Input: head = [1,1,2]
Output: [1,2]
```

### Example 2:

![Example 2](https://assets.leetcode.com/uploads/2021/01/04/list2.jpg)

```
Input: head = [1,1,2,3,3]
Output: [1,2,3]
```

## Constraints

- The number of nodes in the list is in the range `[0, 300]`.
- `-100 <= Node.val <= 100`
- The list is guaranteed to be sorted in ascending order.
