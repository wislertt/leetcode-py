# Longest Substring with At Most K Distinct Characters

**Difficulty:** Medium
**Topics:** Hash Table, String, Sliding Window
**Tags:** neetcode

**LeetCode:** [Problem 340](https://leetcode.com/problems/longest-substring-with-at-most-k-distinct-characters/description/)

## Problem Description

Given a string `s` and an integer `k`, return _the length of the longest_ substring _of_ `s` _that contains at most_ `k` **distinct** characters*.

## Examples

### Example 1:

```
Input: s = "eceba", k = 2
Output: 3
Explanation: The substring is "ece" with length 3.
```

### Example 2:

```
Input: s = "aa", k = 1
Output: 2
Explanation: The substring is "aa" with length 2.
```

## Constraints

- `1 <= s.length <= 5 * 10^4`
- `0 <= k <= 50`
