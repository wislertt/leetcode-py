# Perfect Number

**Difficulty:** Easy
**Topics:** Math
**Tags:**

**LeetCode:** [Problem 507](https://leetcode.com/problems/perfect-number/description/)

## Problem Description

A <a href="https://en.wikipedia.org/wiki/Perfect_number" target="_blank"><strong>perfect number</strong></a> is a <strong>positive integer</strong> that is equal to the sum of its <strong>positive divisors</strong>, excluding the number itself. A <strong>divisor</strong> of an integer <code>x</code> is an integer that can divide <code>x</code> evenly.

Given an integer <code>n</code>, return <code>true</code><em> if </em><code>n</code><em> is a perfect number, otherwise return </em><code>false</code>.

## Examples

### Example 1:

```
Input: num = 28
Output: true
Explanation: 28 = 1 + 2 + 4 + 7 + 14
1, 2, 4, 7, and 14 are all divisors of 28.
```

### Example 2:

```
Input: num = 7
Output: false
```

## Constraints

- `1 <= num <= 10^8`
