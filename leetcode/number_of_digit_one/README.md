# Number of Digit One

**Difficulty:** Hard
**Topics:** Math, Dynamic Programming, Recursion
**Tags:**

**LeetCode:** [Problem 233](https://leetcode.com/problems/number-of-digit-one/description/)

## Problem Description

Given an integer `n`, count _the total number of digit_ `1` _appearing in all non-negative integers less than or equal to_ `n`.

## Examples

### Example 1:

```
Input: n = 13
Output: 6
```

### Example 2:

```
Input: n = 0
Output: 0
```

## Constraints

- 0 <= n <= 10<sup>9</sup>
