# Unique Binary Search Trees

**Difficulty:** Medium
**Topics:** Math, Dynamic Programming, Tree, Binary Search Tree, Binary Tree
**Tags:** neetcode

**LeetCode:** [Problem 96](https://leetcode.com/problems/unique-binary-search-trees/description/)

## Problem Description

Given an integer `n`, return _the number of structurally unique **BST's** (binary search trees) which has exactly `n` nodes of unique values from `1` to `n`_.

## Examples

### Example 1:

![Example 1](https://assets.leetcode.com/uploads/2021/01/18/uniquebstn3.jpg)

```
Input: n = 3
Output: 5
```

### Example 2:

```
Input: n = 1
Output: 1
```

## Constraints

- `1 <= n <= 19`
